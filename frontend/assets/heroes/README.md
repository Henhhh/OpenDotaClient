# Hero artwork

127 PNG files downloaded from the same Steam CDN URLs referenced by the supplied design:
`https://cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/heroes/{key}.png`

Dota 2 artwork belongs to Valve and its respective owners. These are reference game assets for the OpenDota client, not original artwork created by this project. The mapping used by Metro lives in `src/shared/assets/hero-art.ts`.
